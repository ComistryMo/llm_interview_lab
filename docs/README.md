## 历史与目录约定

| 位置 | 用途 |
|---|---|
| docs 根目录 | 当前用户指南、发布入口及被代码引用的 release notes |
| docs/content、research | 内容对照、来源及研究底稿，不直接替代可练题 |
| docs/design、images、performance | 设计决策、带来源截图和性能证据 |
| docs/archive | 旧阶段报告，保留原始事实 |
| plans/active | 尚有产品决策或验收跟踪价值的计划 |
| plans/completed | 已结束或被替代的历史计划，不等于所有未验收项通过 |
