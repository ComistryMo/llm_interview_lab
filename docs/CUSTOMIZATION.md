# 个性化指南

个性化的目标是改变路线权重和训练压力，不是绕过共同 Gate。所有个人配置应进入独立私人仓库。

## 最小档案

从 `templates/LEARNER_PROFILE.md` 填写：

- 目标岗位主线和辅助线；
- 目标时间窗口，不必写精确学校或雇主；
- 每周正常、加班和最低保障时数；
- Python、算法、PyTorch、模型、项目表达和调试基线；
- 已有但尚未核实的项目主题；
- 默认最高帮助等级；
- 时区与复测可用日；
- 明确不进入仓库的资料类型。

## 任务选择规则

先从[课程双轴导航](../curriculum/NAVIGATION.md)按目标岗位找到候选项，再沿依赖边选择最小阻塞点。同一时刻只有一个 Implementation Lane Task；Preview Lane 可以领先 2–4 周，但只看公式、shape、输入输出和官方资料。

任务卡至少要有 ID、前置、输入输出、第一版范围、明确不做、可见/变式测试、提示阶梯、验收问题、D+2/D+7 和降级任务。没有这些字段时先补任务卡，不先写答案。

## 时间强度

- 最低保障周：只做当前任务的一次 45–90 分钟推进、一次旧题复写和状态更新；
- 正常周：实现、算法恢复、Preview、项目口述和周考分块进行；
- 高压周：增加变式、调试和模拟面试，不靠长期熬夜增加时数。

训练债务不能无限滚动。连续两周未完成时，暂停新任务，缩小当前范围并记录真实阻塞；不要通过一次解锁多个任务“追进度”。

## AI 行为验收

用五个场景测试你的助手配置：开始训练只给一个任务；提交时不改答案；H2 不泄露步骤；未授权时拒绝完整答案；遇到项目未知项写“待核实”。任一失败先修适配规则，再继续训练。
