# 中文术语表

中文用户文档以本表为准。首次出现可写“中文（English）”，后续统一使用中文；代码标识符、CLI、Schema 字段、API 与模型名保持英文。

| English | 中文 |
|---|---|
| Profile | 学习档案 |
| Track | 岗位路线 |
| Quest | 闯关路线 |
| Capstone | 综合关卡 |
| Workspace | 个人工作区 |
| Public Tests | 公开测试 |
| Contract Review | 契约审查 |
| Oral Defense | 口述答辩 |
| Retention | 间隔复测 |
| Mastered | 已掌握 |
| Provider | AI 服务 |
| Context Preview | 上下文预览 |
| Approval | 操作审批 |
| Role Profile | 岗位画像 |
| Interview Blueprint | 面试蓝图 |
| Scorecard | 评分卡 |
| Submission | 答案 / 提交（按语境） |
| Grader | 本地 Grader |

避免同页混用“用户档案 / 学习档案 / Profile”“供应商 / Provider / AI 服务”。不得直译出“消费事件”“物化状态”等生硬表达，优先写“记录学习事件”“计算当前进度”。
