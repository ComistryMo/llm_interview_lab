# v0.4.0-alpha.4 · 桌面候选版

状态：候选构建与验收进行中，**尚不可发布**。本文件不是公开 Release 已存在的证明。

## 本轮变化

- 可收起侧栏，移除左下角重复档案装饰；档案切换仍在设置。宽屏面试与代码区更充分使用可用空间。
- 固定代码题默认展示完整中文题面，保留原题切换；不改接口、公开测试和掌握条件。
- 恢复同一档案上次面试配置和相同 SHA 的材料选择；新场次仍确认发送范围，材料变化或撤权后不沿用旧授权。
- 启动恢复上次 AI 连接。连接检测不发送个人材料；普通 API 探测可能按服务商规则计入少量 Token。
- 未提交口述回答和知识练习防抖本地保存，重启恢复不提交、不形成评分。代码保留保存及关闭时的保存/放弃/取消确认，不承诺突然断电后恢复尚未保存的代码。
- 知识搜索复用已验证公开快照的检索文本；公开文件变化会重新验证，不缓存个人授权。
- 刷题新增代码难度、环境与全部已验证题筛选，不把 planned 或缺依赖题显示为当前可运行。
- 设置新增官方 GitHub Release 检查、预发布渠道、下载、取消、SHA-256 校验和打开下载位置。不会自动安装或覆盖正在运行的应用。
- 承接此前的本地流式预览 + Qwen3-ASR 0.6B 停句校准。语音模型仍单独保存在本机，不包含在便携包中。
- 修正独立包主动排除可选依赖时的检测：缺 PyTorch/NumPy 不阻断建档，依赖这些模块的题目仍明确标为不可运行。
- 修正便携包执行入口及公开测试插件；没有 PATH 中的 Python 也能运行自写脚本和公开测试。新建缺依赖练习会给出具体原因，已有代码仍可恢复查看。

## 内容事实

公共目录当前有 96 道资产完整题，其中 84 道 Oracle 验证、12 道契约级；158 个 planned 节点不是可练题。24 道已有验证 D+2/D+7 变式。255 张知识卡。详细口径见 [覆盖快照](content/release-candidate-coverage-20260909.zh.md)。

待审 AUTHOR 补充不进入 ready、Oracle 或 retention-ready 统计。发布包必须通过公共文件 SHA 清单比对，不能以源码中存在替代实际随包交付。

## 安装与更新

Windows 下载 `LLMInterviewLab-Windows-x64-portable.zip`，解压到新目录；退出旧应用后启动新版 `LLMInterviewLab.exe`。macOS Apple Silicon 使用 `LLMInterviewLab-macOS-arm64.dmg`；候选版实际 Qt 6.11 依赖要求 macOS 13+，不沿用旧版的 12+ 声明。退出旧应用后再替换应用，不删除应用数据目录。无自动安装或静默替换。

保存原数据目录和旧包即可回退应用。新版启动只同步公共课程和规则，不覆盖 Profile、events、回答草稿、材料、连接引用或语音模型。SHA-256 只证明与发布清单一致，不是代码签名或安全审计。

## 尚需的门禁

最终完整回归、Windows 独立包启动及升级、macOS arm64 CI/Artifact 尚待本轮报告确认。没有验证的项目不能按历史报告写成通过。真实 AI、麦克风、macOS 用户实机验收与替身测试分开记录。便携包未内置可选 PyTorch 时，依赖 PyTorch 的题目不可运行；保留说明和源码安装路径，不冒充全题可运行。
