# 分级提示（待审）

- H1：先查 NumPy 累积索引的文档，关注 repeated indices，不要把高级索引写回等同于 scatter-add。
- H2：将计算图画成一个参数指向两条边。每路单独为零时，另一条边的梯度应该仍然存在。
- H3：用重复两次的同一 ID 建立最小反例，再构造一个同时包含两路输出的标量目标进行有限差分。最后检查 hidden 与 token 的 batch 并不要求相同。

深入条件：能解释参数共享与链式法则后，再问频次归一化、padding 和稀疏/稠密梯度的取舍。薄弱时只问“同一个标量参与两次计算时，梯度如何合并”。能用反例定位覆盖、遗漏某一路或额外平均后即可结束，不需凑轮数。
