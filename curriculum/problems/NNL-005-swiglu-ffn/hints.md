# NNL-005 分级提示

## H1

先核对题面接口、归约轴、允许的 API；阅读题面末尾的技术来源。

## H2

两个独立输入投影得到 `[B,T,H]`，对 gate 分支激活后逐元素相乘，最后投影回 D。它在每个 token 上应用同一组权重，不能把 T 维混成注意力，也不能误写成每个位置有一套独立参数。

## H3

先实现最小非退化输入，再补状态和边界。任一输入投影矩阵全零时输出全零；只改变第 t 个 token 的输入，在本层内不会改变其他 token 的输出；批处理应与逐 token 循环一致。参数量为3DH；两层 GELU FFN 的隐藏维度4D时参数约8D²，等预算 SwiGLU 的 H≈8D/3，实际可因硬件对齐取整，不是所有模型都必须使用此数值。

## 口述追问

融合 gate/up 投影能减少哪些启动与访存成本？为什么输出维度回到 D 才方便接残差？定义参考 [GLU Variants Improve Transformer](https://arxiv.org/abs/2002.05202)。
