# TOK-001 分级提示

## H1

## H2

频次应乘词频；`aaaa` 中统计相邻 `aa` 有 3 次，但这一轮只能执行 2 次不重叠合并。以初始不同词条的 token 总数为 `N`、迭代次数为 `M`，全扫描教学版在 token 哈希/拼接视为常数时上界 `O(MN)` 时间、`O(N+M)` 空间；真实字符串操作还要计算字符长度。无 pair 时提前终止。

## H3

先实现最小非退化输入，再补状态和边界。词条 `("a","a","a","a")`、频次 1，一轮结果为 `("aa","aa")`；空词条不报错；打乱输入词条顺序不改变 tie-break 结果；merges 保存再加载后分词一致。
