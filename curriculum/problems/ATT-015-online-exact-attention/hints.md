# ATT-015 分级提示

## H1

先核对题面接口、归约轴、允许的 API；阅读题面末尾的技术来源。

## H2

每个 query 行维护最大值 m、分母 l、未归一化输出向量 a。新块分数为 s，令 `m'=max(m,max(s))`、`α=exp(m-m')`、`p=exp(s-m')`；更新 `l'=α*l+sum(p)`、`a'=α*a+pV_block`。结束输出 a/l。关键是同时重缩放旧的分母和分子，不能把各块 softmax 输出简单平均。

## H3

先实现最小非退化输入，再补状态和边界。C=1、C>S、S%C≠0 都应对齐完整 attention；把所有 key 行按相同排列重排 K/V 后输出不变；大幅放大但未导致点积溢出的 Q/K 仍不 NaN。空块不进入更新；若扩展 mask，须额外处理一个 query 在前几个块都无合法 key 时的 `-inf-(-inf)`。
