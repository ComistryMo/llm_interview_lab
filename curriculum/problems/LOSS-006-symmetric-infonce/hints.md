# LOSS-006 分级提示

## H1

先核对题面接口、归约轴、允许的 API；阅读题面末尾的技术来源。

## H2

沿 D 做 L2 归一化；相似度 `S=A_norm @ B_norm.T /τ`；目标标签为 `arange(B)`，分别对 S 与 Sᵀ 做交叉熵。不能屏蔽对角线——它恰好是本题正样本。若存在重复图文对或多正例，应改正样本契约与分子，而非继续把它们当负例。

## H3

先实现最小非退化输入，再补状态和边界。两组特征都为单位阵时，对角分数最大且 loss 可解析；所有相似度相同，loss=`log(B)`；同时按同一排列打乱两组，loss 不变；只打乱一组则必须更新目标索引。拒绝零向量能使题意清楚；若使用 eps 归一化，要解释其实际相似度。

## 口述追问

多卡 all-gather 后 target index 要不要加 rank 偏移？远端 embedding 是否保留梯度会怎样改变训练？本题是配对检索变式；基础目标参考 [CPC / InfoNCE 原论文 §2.3](https://arxiv.org/pdf/1807.03748)，图文双向形式参考 [CLIP 原论文](https://arxiv.org/abs/2103.00020)。
