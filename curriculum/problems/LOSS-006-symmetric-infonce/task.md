# LOSS-006 · InfoNCE 与图文双向对比学习

资料映射：AI11。这是原创训练任务，不代表某公司必考题。

推荐准备：[LOSS-014](../LOSS-014-cross-entropy/task.md)。推荐顺序不等于硬解锁条件；实际解锁条件见课程入口。

## 接口

```python
def paired_infonce(a, b, temperature=0.1): ...
```

## 题目要求

- A/B[N,D]，N≥2，同一行是唯一正例
- 非零向量，temperature>0。L2 归一化后计算所有配对相似度除温度
- 返回 A→B 和 B→A 两方向 CE 的均值。不得屏蔽对角线，不调用现成对比损失
- 允许交叉熵基础运算。零向量抛 ValueError。O(N²D) 时间，O(N²) 相似度矩阵。多正例、多卡 target offset 是口述变式，不改变本题标签。

## 共同约定

输入不允许被原地修改（接口明确的状态更新除外）。除题目指定的空输入与异常，输入形状合法、数值有限；不要增加与本题目标无关的校验。张量位于同一设备；浮点使用 float32/float64，保持输出设备与明确的梯度路径；禁止直接调用题目要求手写的整层/算法。

## 验收与复盘

可在编辑器中自行构造输入并运行，也可运行公开测试。测试通过只是实现证据，不等于掌握。完成后解释 shape、复杂度、一个失败边界和测试依据；提示见 hints.md。
