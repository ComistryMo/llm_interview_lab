# ATT-020 分级提示

## H1

先核对题面接口、归约轴、允许的 API；阅读题面末尾的技术来源。

## H2

沿序列维拼接新 KV；当前 query 的绝对位置是 `P+arange(L)`，key 的位置为 `arange(P+L)`；允许条件为 `key_position <= query_position`，再叠加样本有效长度约束。调用 AI02 的语义参考即可得到教学版。若 K 使用 RoPE，缓存保存已按其真实位置旋转一次的 K，不能每步重复旋转历史 K。

## H3

先实现最小非退化输入，再补状态和边界。`L=1` 时该 query 应能访问全部合法历史及自身；直接对 `[1,P+1]` 执行左上对齐的 `tril()` 只允许第一个 key，会产生隐蔽错误。实际 batch 若每条样本历史长度不同，不能共用单一 P 假装绝对位置相同；本题基础版先约定等长无 padding，扩展版再接入逐样本位置。
