# ATT-023 分级提示

## H1 · 官方文档 / 单一语法

查看 reshape、transpose 和 einsum 的轴标签；RoPE 的位置广播需保留 batch 轴。

## H2 · 概念方向

把内容匹配与位置匹配分开；历史 latent 尚未被永久展开，历史 rotary key 已经旋转。

## H3 · 结构步骤

画出两条低秩投影、两条旋转支路、缓存追加和每头打分的形状。用一个 token 检验 value 路径，再用多 token 分块比较 full 与 cache 输出，最后检查缓存元素数和所有梯度。

## 复测方向

关闭原实现后在展开与吸收两种计算组织之间迁移，再构造历史 key 二次旋转的反例。尚无独立已验证 D+2/D+7 资产；H4/H5 后须新的无帮助变式。
