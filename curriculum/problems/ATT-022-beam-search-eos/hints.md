# ATT-022 分级提示

## H1

先核对题面接口、归约轴、允许的 API；阅读题面末尾的技术来源。

## H2

对活跃路径扩展词表，累计父路径 log-prob；将新候选与已经完成的保留路径合并，按总分选择最多 K 项，分数相同时按 token ID 序列的字典序决定；已结束项不再扩展。初始只有一条空回答路径，不能复制 K 份相同路径。运行到所有保留路径结束或长度上限。这是明确的教学 beam 规则；维护独立 finished 队列的其他实现需要另定候选入队与早停规则。若加长度惩罚，评分和早停上界都要重写。[Transformers Generation Strategies](https://huggingface.co/docs/transformers/en/generation_strategies)

## H3

先实现最小非退化输入，再补状态和边界。手工构造小词表概率树，比较累计概率而非逐步概率之和；检查 EOS 完成项只保存一次。对无长度惩罚基础版，K=1 应符合明确 EOS 规则下的 greedy。接 KV cache 时按选择结果同步重排父 beam 的缓存。

## 口述追问

改变一个输入规模或边界条件后，公式和复杂度是否仍成立？给出可复现的小例子。
