# INF-013 分级提示

## H1

先核对题面接口、归约轴、允许的 API；阅读题面末尾的技术来源。

## H2

输出 `XWᵀ+b+(α/r)(XAᵀ)Bᵀ`。A 随机初始化、B 零初始化；合并得到 `W_merge=W+(α/r)BA`。显式管理 merged 状态，重复 merge 不得累计相同更新；若为可逆原位 merge，进入训练前必须正确 unmerge。更容易验收的方案是生成独立合并副本。

## H3

先实现最小非退化输入，再补状态和边界。初始化时与基础层完全等价；初次反传通常 B 有梯度、A 的梯度为零，不能据此误判 A 断图；训练一步后保存/加载 adapter 输出一致；合并前后固定输入输出近似相等，W 不参与梯度。FP16 就地加减不保证逐 bit 可逆。

## 口述追问

为什么 A、B 都初始化为零会妨碍学习？有 dropout 或量化基础权重时，何时才能要求精确合并？接口与初始化可参考 [微软 LoRA 作者仓库](https://github.com/microsoft/LoRA)、[原实现层定义](https://github.com/microsoft/LoRA/blob/main/loralib/layers.py)。
