# LOSS-010 分级提示

## H1

## H2

按 score 从小到大排序，按同分值成组处理。假设本组正例 p、负例 n，已有更低分负例数 `neg_before`，本组贡献为 `p*neg_before + 0.5*p*n`；累加后除以 `N_pos*N_neg`。这是正例比分更高为赢、同分半赢的配对定义的高效实现。

## H3

先实现最小非退化输入，再补状态和边界。完美排序=1、完全反序=0、全同分=0.5；`labels=[0,1],scores=[0.5,0.5]` 必须为0.5；改变同分样本原始顺序不改变结果；小 N 时用全配对 `O(N²)` 参考校验。不要拿阈值后的 0/1 预测代替连续分数。
