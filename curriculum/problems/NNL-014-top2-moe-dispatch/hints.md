# NNL-014 分级提示

## H1

先核对题面接口、归约轴、允许的 API；阅读题面末尾的技术来源。

## H2

找出 `[N,2]` 专家索引和权重，展平为 2N 条路由，按专家 gather 输入；运行专家，将 `gate*expert_output` 按原 token id 用 `index_add/scatter_add` 累加。切忌普通赋值覆盖同一 token 的另一专家贡献。离散 Top-k 索引不可导，但被选中 logits 的 gate 与专家参数仍能反传；不要 detach 权重。

## H3

先实现最小非退化输入，再补状态和边界。所有专家都是恒等映射时，Y=X；两个专家分别返回 x 和 2x 时，可手算 gate 加权结果；某专家没有 token 时不报错；路由 batch 打乱再恢复顺序后结果不变。对每个 token 的 gate 求和应为1，不因专家分组漏加。

## 口述追问

增加 capacity 后，超出的 token 如何处理并计数？如何写 Top-1 的负载均衡辅助项，并说明 Top-2 统计分母需要重新定义？稀疏路由与 Top-1 辅助项参考 [Switch Transformers 原论文 §2.2](https://arxiv.org/pdf/2101.03961)。
