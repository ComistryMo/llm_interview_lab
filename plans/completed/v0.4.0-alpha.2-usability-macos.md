# v0.4.0-alpha.2 中文体验、可靠性与 macOS

## 目标与可观察结果

将 v0.4.0-alpha.1 收敛为中文优先、首次使用更短、同时提供 Windows x64 与 macOS Apple Silicon 桌面包的 Alpha.2。完成时：用户文档和 GUI 默认中文；No-AI 始终可用；打包桌面端使用平台应用数据目录；`macos-15` arm64 CI 能构建并实际启动 `.app`，生成 `.app.zip`、`.dmg` 与校验和；Windows 包不退化；PR、main、tag 与 prerelease 一致。

## 当前仓库事实

- 基线：`main@6874c54`，公开版本 `v0.4.0-alpha.1`。
- Python 3.11.9；使用 E: pytest 临时根时为 `340 passed, 11 skipped`。系统 C: 临时目录空间不足会造成伪失败。
- Catalog：41 ready / 188 planned / 32 oracle / 24 retention-ready / 0 field runs。
- 桌面端：PySide6 + Qt Quick；Windows one-file CI；源码模式使用仓库内 Workspace，打包模式当前仅以 `%LOCALAPPDATA%` 推导数据根。
- AI：No-AI、OpenAI/OpenAI-compatible/Ollama、源码安装的 Anthropic/Gemini、系统 keyring，以及 Codex App Server JSONL/stdio。
- 当前 README、大部分用户文档和 QML 文案为英文；没有 macOS Job 与 Artifact。

## 范围与明确不做

范围仅包括中文文档/GUI、Onboarding/Home/连接可用性、中文可执行错误、平台数据路径与旧桌面目录安全迁移、Keyring/Codex macOS 兼容、日志与启动测量、macOS arm64 打包、跨平台/文档/隐私测试、PR 与 prerelease。

不新增课程、Role、Skill、Blueprint、Catalog 节点、数据库、服务端、Web/TUI、多 Agent Runtime、遥测、自动更新、云同步或独立 macOS 业务逻辑。不读取、迁移或提交任何真实 Profile；迁移测试只使用虚构临时数据。不宣称 Intel Mac、Apple Developer ID 签名、公证或真实 Field Run。

## 里程碑与验证

1. **中文与首次使用**：集中 GUI 字符串，中文化 Onboarding/Home/Exercise/Interview/Connections/Settings 和可执行错误；README、核心用户/贡献文档及 GitHub 模板中文优先。验证桌面 controller/QML 与文档契约。
2. **平台可靠性**：源码仍用仓库 Workspace；打包端使用 `QStandardPaths.AppDataLocation`；旧 Windows 数据只在用户确认后复制迁移并保留备份；增加打开数据/日志目录、脱敏日志、Codex 可执行文件选择与常见路径探测。验证 Unicode/空格路径、Mock Keyring、No-AI 与连接失败。
3. **macOS arm64**：固定 `macos-15` 标准 M1 runner；生成原创图标与 `.icns`；使用 `pyside6-deploy`/Nuitka 构建 `.app`，校验 Info.plist、arm64、ad-hoc 签名、内部 `--version`/`--smoke-test`；用 `ditto`/`hdiutil` 生成 `.app.zip`/`.dmg` 和 SHA-256，并解包检查隐私。
4. **发布**：重打 Windows x64；运行全量、CPU PyTorch、桌面/文档/隐私/clean-clone 测试；推送分支、Draft/普通 PR，远端全绿后合并 main，发布 `v0.4.0-alpha.2` prerelease，归档本计划。

## 风险、回退与停止条件

- 数据迁移绝不删除旧目录；目标已存在或副本校验失败则停止并保留源数据。回退为继续使用旧版应用目录。
- Keyring 失败不回退明文，连接保持未配置，No-AI 可继续。
- macOS 包若无法真实启动，不发布该 Artifact，也不发布 Alpha.2。
- 无 Apple 凭证时只做 ad-hoc 签名，文档明确“未 Developer ID 签名、未公证”。
- 触发用户给定的个人数据、历史重写、CLI 破坏或许可证冲突条件时停止询问。
