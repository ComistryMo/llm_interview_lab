# v0.4.0-alpha.4 Quiet Forge 桌面工作台重设计

## 目标与可观察结果

本计划把当前偏卡片后台的桌面界面逐步收敛为安静、精确、适合长时间训练的本地工作台。S0/S1 冻结了真实交互合同并建立主题、首批共享组件与 Shell；S2 只收敛首次使用最关键的 Onboarding、Home 与 Learn，不扩展领域能力。

可观察结果：

- Light/Dark 具有一致的 canvas、chrome、surface、文字、边界和状态层级；
- Shell 在 900×620 使用紧凑图标栏，在 1040px 以上使用标准栏，在 1400px 以上才展开文字侧栏；
- 全应用只有一个页面 H1；Windows/Linux 不再显示突兀的窗口内灰色菜单条，同时 About、Settings、Quit、Continue、Run Tests 仍可达；
- Command Palette、Toast、Codex approval 保持既有事实来源和测试锚点；
- 首批控件具备 hover、press、focus、disabled/busy 与可访问名称；
- screenshot/test 可用非持久化参数固定字体比例和 motionScale=0；
- 新 QML、SVG 与许可同步进入源码包及 Windows/macOS deploy 配置。

- 证据栏使用真实内容高度，知识详情固定到 ScrollView 可用宽度并禁止水平滚动；

## 风险与回退

- 旧页面大量依赖 `window.colors`：AppTheme 必须提供兼容 palette，逐页迁移；
- 组件提取可能破坏测试锚点：objectName 留在真实可观察/可交互对象；
- 新 QML/SVG 可能漏打包：同一提交同步两份 deploy spec 与 package-data；
- 动效可能使截图不确定：截图模式强制 motionScale=0；
- compact 模式可能隐藏主动作或 approval：出现即停止并回退 Shell 布局；
- 任何领域状态需求、binding loop、持续 QML warning、only-offscreen pass 或来源不明并行改动都触发停止。
