# v0.4.0-alpha.3：真实交互与可靠训练

## 目标与边界

本轮只交付三项真实改善：

1. 首次训练能从中文学习档案、岗位选择进入第一题，并对失败给出可操作说明；
2. 练习始终保存并测试编辑器中的最新 revision，Review、到期复测和提交状态保持一致；
3. 模拟面试只使用与 Round 技能、难度和环境匹配的题，评分证据可恢复，桌面截图与发布说明可复核。

不新增 Problem、Interview Item、Role、Skill 或 Blueprint；不修改 Event 或 mastery Schema；不重构 Controller、Provider 或 QML 架构。仅允许为明确标记的非代码专项面试，向 Profile-local Interview Session Schema 增加向后兼容的可选字段。

## 已确认事实与决策

- 当前同步基线为远端 `main@fcb0dd9`；`v0.4.0-alpha.3` 尚未发布，公开桌面版本仍为 `v0.4.0-alpha.2`。
- Skill 映射以 `curriculum/skills/ontology.yaml` 为准；硬依赖、mastery 和 retention 继续由确定性核心裁决。
- Interview 缺少精确技能、难度或运行环境候选时，在写 session 前返回不可用，不降低要求或随机兜底。
- 只有完整蓝图唯一缺口为 PyTorch Coding Round、且其余 Round 均有严格匹配固定题时，才允许用户显式选择“非代码专项面试”。该 Session 保留原 Round 权重、不重新归一化，结果始终标记 partial evidence / incomplete，不伪装成完整岗位面试。
- Retention 明确区分 future、due、missing asset 和 missing environment；只有 due 且可执行的项目显示动作。
- Interview session/result 是事实源，报告是可再生成视图，不反向修改 Practice mastery。
- 未取得真实 Windows 11 双击证据时，发布结论必须标记 `BLOCKED_BY_MISSING_WINDOWS_RUNTIME`。

## 批次与所有权

- Core（W3）：Interview preflight、Practice/Retention identity、报告恢复和定向测试。
- UI（W1）：Home、Exercise、Interview 的真实动作、1080×680 可达性和 QML 定向测试。
- 集成（A0）：审查提交、修 P0/P1、生成中文多尺寸截图，并组织 R1/R2/R3/R5 独立复核。
- 发布（A0）：README、CHANGELOG、版本、截图 manifest、Artifact/Privacy 检查和本计划。

共享文件只有 A0 写入；未知未跟踪文件不得删除、读取为产品事实或提交。

## 验证预算与发布 Gate

- 开发阶段只运行定向测试；所有实现和复核修复完成后只再运行一次本地全量。
- Release Candidate CI 只触发一次；失败时只重跑失败 Job。
- Release Gate：无 P0/P1；No-AI 首次路径、最新 revision、Review/Retention、Interview 恢复通过；截图可读且 1080×680 不遮挡核心动作；Artifact 无 Profile、材料、答案、Transcript、Key、Oracle 或 Private Tests；README、main、Tag、Release 只陈述已验证事实。

## 当前门禁结果（2026-08-31）

- CI 可选依赖收集、跨平台 Profile 路径、发布链接真实性、岗位首题可达性、`ready` 前置与准备度证据口径已分别提交。
- 无 PyTorch 时，算法与推理岗位只有在全部 Coding Round 均因该环境缺失、其余固定 Round 完整时，才显示显式非代码专项入口；混合可运行代码轮次与内容缺口均不会降级。
- Core 与产品视觉独立复核均无剩余 P0/P1；1080×680 的合成专项设置和确认框已人工查看。
- 本轮唯一一次本地全量回归：`475 passed, 13 skipped`；跳过项均为当前普通 Windows 账户无 symlink 权限的既有平台条件。
- 仍待远端 CI 与真实 Windows 11 Standalone 双击验收；在此之前不创建 Alpha.3 Tag 或 Release。
