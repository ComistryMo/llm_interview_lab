# Project Claim Template

Use this template only for a public-safe summary that you wrote yourself.
Verify facts inside an environment where you are authorized to view them, but
never copy the evidence itself into this repository or share it with an AI.

## Non-negotiable privacy boundary

Do **not** record or attach any employer, client, school, or research partner:

- source code, data, prompts, samples, screenshots, or model artifacts;
- repository paths, class/function names, commit IDs, branches, or issue IDs;
- configurations, commands, shell history, logs, dashboards, or checkpoints;
- internal model/project names, unreleased methods, exact metrics, or volumes;
- documents, chat messages, meeting notes, credentials, or access details.

An ignored or private-looking directory is not an approved storage location.
If disclosure is uncertain, write `needs verification` and omit the detail.

## AI coach rules

The AI coach may challenge consistency, ask for a toy reproduction, and mark a
claim as unverified. It must not ask to inspect internal evidence, infer missing
facts, invent metrics, or turn common industry practice into a project claim.
