# Learner Profile

> Public alpha fixture. 在私人训练副本中用 `templates/LEARNER_PROFILE.md` 替换本页；不要在公共上游记录身份、雇主或内部项目事实。

## 目标方向

- 主线：LLM/VLM 算法与后训练；
- 辅线：Agent 场景与训练框架理解；
- 方法：任务驱动补 Python/PyTorch，单任务 Gate 推进。

## 当前基线

- 算法思维有既往基础，但 Python 面试实现需要恢复；
- Python 函数、异常、容器、类和测试尚需在真实任务中巩固；
- Loss、Optimizer 和训练循环尚不能稳定闭卷实现；
- 简历或项目中出现过的技术一律不自动判定掌握。

## 训练偏好与约束

- 不安排连续数周的纯语法课程；
- 反馈严格、具体、有测试证据；
- Implementation Lane 同时只有一个主任务；
- 默认帮助上限 H2，升级必须记录；
- 高压来自限时、闭卷、变式和追问，不来自长期熬夜。

## 隐私

- 只记录公开安全的抽象流程和 toy implementation；
- 未核实的项目事实写“待核实”；
- 不将任何第三方内部材料复制到仓库或提供给 AI。
