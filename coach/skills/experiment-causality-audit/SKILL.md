# experiment-causality-audit

版本：1

- 适用：回答声称指标改善、实验结论、训练奖励或稳定性收益。
- 不适用：没有任何结果主张；或尚未讲过该经历。
- 必要输入：实际结果主张、对照条件、授权范围内的回答，不索要内部指标。
- 追问动作：锁定一项结论，问改变了哪些变量及什么观察会推翻它；困难核对预算、数据泄漏和替代解释。
- 空泛回答识别：只说效果更好、奖励上涨，不能等同泛化提升。
- 停止条件：对照和替代解释已清楚就换方向；未做实验只记未验证，不能要求编数据。
- 禁止行为：不把训练 reward 当独立评测；不索取商业机密。
- 好坏对照：好：奖励和独立成功率方向不一致时，哪个对照能区分两种解释？坏：奖励涨了，所以能力提高了，对吗？
