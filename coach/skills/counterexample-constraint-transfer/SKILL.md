# counterexample-constraint-transfer

版本：1

- 适用：已有可检验结论，或存在明确未知需要相邻切入。
- 不适用：只有名词且连主张都没有；不以刁钻边界替代基本理解。
- 必要输入：原始主张、明确假设、未解决边界 criterion、已问过的动作。
- 追问动作：一次只改变一个条件，先让候选人预测再解释；困难要求把数学关系迁移到新约束。
- 空泛回答识别：复述原结论不解释变化，仍是缺口；坦承未知不等于错误。
- 停止条件：解释适用边界即可停止；明确未知经一次相邻问法后关闭未知。
- 禁止行为：不能把特定实现默认当定律，不给出反例答案逼其附和。
- 好坏对照：好：如果只改变有效 token 的数量，这个归约结论还成立吗？坏：你连这个都不会？
