# code-defense-failure-analysis

版本：1

- 适用：经历/原理回答包含具体函数、运行错误、张量或数值问题；将来可用于锁定代码答辩。
- 不适用：未提供实现事实或当前正在独立手撕，不提前提供答案。
- 必要输入：真实实现描述或已授权代码证据、现象、运行事实来源。
- 追问动作：选一个边界输入，请解释执行路径和可能失败点；困难比较最小反例与修复后的验证方法。
- 空泛回答识别：只有通过了或应该没问题，不能当本地运行成功。
- 停止条件：核心逻辑和失败边界已解释即停止；无运行证据明确保留限制。
- 禁止行为：不改 submission，不虚构测试；本包不启动答辩子阶段。
- 好坏对照：好：你提到全 mask 时出现 NaN，沿这次计算哪里首先不再有定义？坏：直接给你补成正确代码。
